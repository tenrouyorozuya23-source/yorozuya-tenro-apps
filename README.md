## 🛠 開発ツール一覧

### 1. 🎬 STAGE CUT — 舞台切り抜きエディタ
**`stage-cut/`**

舞台・ライブ映像を再生しながらワンクリックで切り抜き点を指定し、トランジションを設定して書き出せるWebアプリ。

**主な機能**
- 動画再生しながらIN点・OUT点をワンクリックで指定
- カット・フェード・クロスフェード・ワイプ・暗転のトランジション選択
- クリップのドラッグ＆ドロップで順番変更
- YouTube横型・Shorts縦型・Instagram正方形のフォーマット対応
- FFmpegコマンドを自動生成して書き出し
- キーボードショートカット対応（I/O/Space/←→）

**使用技術**
- HTML / CSS / JavaScript
- FFmpeg（コマンド生成）

**デモ**
- [STAGE CUT を開く](https://tenrouyorozuya23-source.github.io/yorozuya-tenro-apps/stage-cut/index.html)

### 2. 🎭 Stage Booking & POS Manager — 舞台予約・物販管理システム
**`stage-booking-pos-manager/`**

舞台公演の予約受付から当日の受付・物販レジまでを一元管理するGAS製統合システム。実際の公演「天狼祭2026」で使用中。

**主な機能**

**予約管理**
- Googleフォームと連携した予約の自動受付・管理
- 予約番号の自動発行（R-001形式）
- 全通券の全公演自動展開
- キャスト別予約リストのWebアプリ表示
- 残席リアルタイム更新

**LINE Bot連携**
- キャストがLINEで取り置き予約を追加
- 毎日定時に予約状況をLINE通知
- キャンセル申請をLINEで処理

**当日受付アプリ**
- 公演ごとの予約一覧表示
- 現金・クレカで受付処理
- 予約番号・名前で検索
- 来場統計のリアルタイム表示

**物販レジ（POSシステム）**
- 商品マスタから自動読み込み
- カート機能・数量変更
- 現金（おつり計算）・クレカ対応
- 売上ログ自動記録
- レシートPDF自動生成・Googleドライブ保存

**売上管理**
- 公演ごと・決済方法別の売上集計
- クレジットカード手数料の自動計算
- 現金手元合計・口座入金額の自動算出

**使用技術**
- Google Apps Script（GAS）
- Google Spreadsheet / Forms / Drive
- LINE Messaging API
- HTML / CSS / JavaScript

### 3. ⛓ CHAIN FX — 光る鎖アニメーションシミュレーター
**`chain-fx-simulator/`**

黒背景の画面上で発生源と到着地点を指定すると、光る鎖が勢いよく出現するエフェクトシミュレーター。舞台・配信演出のイメージ確認用。

**主な機能**
- クリック2回（発生源→到着地点）で直線発射、ドラッグで自由な曲線を描いて曲線に沿って発射
- 勢いのある出現アニメーション（しなり・着弾衝撃波・火花パーティクル）
- 鎖の色をプリセット6色＋カスタムカラーで変更
- 光量・太さ・出現スピード・しなり量をスライダーで調節
- 自動消滅時間の設定（2〜20秒 / 常時表示）
- ランダム発射・全消去ボタン、タッチ操作対応
- アニメーションを標準MP4動画（H.264）として録画・ダウンロード（Rキーで開始/停止）。Windows標準プレイヤー・スマホ・編集ソフトでそのまま再生可能

**使用技術**
- HTML / CSS / JavaScript（Canvas 2D）

**デモ**
- [CHAIN FX を開く](https://tenrouyorozuya23-source.github.io/yorozuya-tenro-apps/chain-fx-simulator/index.html)

## 💡 開発の背景

映像・配信エンジニアとして舞台公演に携わる中で、以下の課題を感じていました。

```
・予約管理がLINEやメールのやり取りで煩雑
・当日の受付がアナログで時間がかかる
・物販の売上集計を手作業でやっていた
・90分の舞台映像から切り抜きを作るのに時間がかかる
・毎月の交通費集計がPASMO履歴を見ながら手入力で非常に面倒
・レシートや領収書の経費登録が後回しになりがち
・請求書作成に毎回同じ作業を繰り返していた
```

これらを解決するために独学でプログラミングを学び、実際の現場で使えるツールとして開発しました。

## 🔨 現在開発中

### 4. 💬 LINE Business Automation — 公式LINE業務自動化システム
**（開発中）**

公式LINEアカウントをハブとして、日常業務のあらゆる作業をLINEから自動化するシステム群。

**経費精算LINE Bot**
- レシート・領収書・利用明細のスクリーンショットをLINEに送信
- Claude Vision APIが画像を自動解析（店名・日付・金額・品目を抽出）
- 経理ソフト **Freee** に自動で経費登録
- 手入力ゼロで経費精算が完結

**請求書作成LINE Bot**
- LINEで会話するように質問に答えるだけで請求書が完成
- Freee APIと連携して請求書を自動作成・PDF発行
- 毎月の請求書作成作業を数分に短縮

**交通費自動計算システム**
- PASMOの1ヶ月分の履歴CSVをLINEに送信するだけで自動集計
- 乗車日・乗降駅・金額を自動読み取り
- 目的地・仕事内容を自由に追記できる入力フォーム
- 1日に複数件・複数の移動手段にも対応
- GoogleスプレッドシートおよびFreeeに自動記載
- 毎月の交通費まとめ作業をほぼゼロに

**使用予定技術**
- Python / Flask
- LINE Messaging API
- Freee API（経費・請求書）
- Claude Vision API（レシート画像解析）
- Google Sheets API
