# freee会計アシスタント 運用ガイド

合同会社萬屋天狼の freee会計 を Claude が「専属税理士」として処理するための仕組み一式。

## できること

| やりたいこと | 使い方 |
|---|---|
| 健康診断（状態チェック＋売上・経費・役員借入金/貸付金の確認） | チャットで「健康診断して」/ `/freee-checkup`。定期自動実行は下記「定期実行の設定」参照 |
| 経費の登録 | 「〇月〇日に△△を買った、経費にして」と書くだけ。下のフォームを使ってもOK |
| 未処理明細の経費化 | 「未処理の明細を処理して」 |
| 領収書写真の自動経費化 | 領収書の写真を**チャットに添付して送るだけ**。読み取り→科目判定→登録まで自動 |
| 請求書・領収書・見積書の作成 | 「請求書作って」と言うとフォームが出る。下のフォームを埋めて送ってもOK |

## Sonnet 5 での運用（Fable 5 の使用量節約）

この仕組みは、事業所固有のID（勘定科目・税区分・口座・取引先）と手順をすべて Skill と `references/company-master.md` に焼き込んであるため、**モデルが探索・推論する余地を減らしてあり、Sonnet 5 で問題なく動く**。

- **新しいチャットを開くときはモデルに Sonnet 5 を選ぶ**（このリポジトリを開けばSkillと資料が自動で読み込まれる）
- 長いチャットを使い回すとコンテキストが膨らみ消費が増えるので、**用件ごとに新しいチャットを開く**のが最も節約になる
- Fable 5 は「仕組み自体の改修」（Skillの修正・新機能追加）のときだけ使えば十分

## 定期実行の設定（初回のみ手動）

セッションからAPI経由で作ったルーチンには freee コネクタを添付できない制限があるため、claude.ai の**ルーチン（定期実行）UI から一度だけ**設定する:

1. claude.ai → Code → ルーチン（Routines / 定期実行タスク）→ 新規作成
2. リポジトリ: `yorozuya-tenro-apps` / モデル: **Sonnet 5** / コネクタ: **freee** を有効化
3. スケジュール: 毎週月曜 9:00（JST）など好みの頻度
4. プロンプトに以下を貼り付け:

```
freee-checkup Skill を実行して、freee会計の健康診断レポートを作成してください。
売上高・経費合計・役員借入金/役員貸付金の残高・未処理明細・期日超過の取引を含め、
要対応事項があれば明確に列挙してください。データの作成・変更はしないでください。
```

## ファイル構成

```
CLAUDE.md                              … 全セッション共通の指示（入口）
freee-accounting/
  README.md                            … このファイル（運用ガイド・フォーム）
  references/company-master.md         … 事業所マスタ（各種ID焼き込み）
  references/account-items.tsv         … 勘定科目 全198件
.claude/skills/
  freee-checkup/SKILL.md               … 健康診断・財務サマリー
  freee-expense/SKILL.md               … 経費登録・未処理明細の経費化
  freee-receipt/SKILL.md               … 領収書写真→自動経費化
  freee-billing/SKILL.md               … 請求書・領収書・見積書の作成
```

## メンテナンス

- 勘定科目・口座・取引先を freee 側で追加したら、`references/company-master.md` の更新を Claude に依頼する（「マスタを最新化して」でよい）
- 消費税の経過措置: 免税事業者等からの仕入は 2026-10-01 から控除割合が80%→50%に変わる（税区分 189→190）。Skillに織り込み済み
- 自動実行の変更・停止は「毎週の健康診断を止めて/毎日にして」と依頼すればよい
