# 領収書写真 → 自動経費化

事業所: 合同会社萬屋天狼（company_id: **10939384**）。
科目・税区分・口座の対応は `.claude/skills/freee-expense/SKILL.md` の表と `freee-accounting/references/company-master.md` に従う。

## 手順

### 1. 画像を読み取る

送られた画像（複数枚なら1枚ずつ）から以下を抽出する:

- 発行日（和暦なら西暦に変換）
- 合計金額（税込）
- 店名・発行者名
- 内容（品目。但し書きや明細行から）
- 税率の内訳（8%軽減対象が含まれるか）
- インボイス登録番号（T+13桁）の有無
- 支払手段の手がかり（「クレジット」「現金」等の記載）

読み取れない項目がある場合のみユーザーに質問する。**画質不良で金額か日付が読めない場合は登録せず再送を依頼する。**

### 2. 科目と税区分を判定

freee-expense の早見表で科目を決める。税区分:
- 通常 → 136 / 飲食料品 → 163
- 登録番号なし → 経過措置（〜2026-09-30: 189/187、2026-10-01〜: 190/188）

### 3. 支払方法を判定

- レシートに「クレジット」等の記載 → freeeカード 2568791 か PayPayデビット 1971666 を推定（不明なら確認）
- カード・銀行引落しの場合、同期明細との二重計上に注意: `GET /api/1/wallet_txns`（limit 100）で同額・近い日付の消込待ち明細（status=1）がないか確認し、あればその明細の消込として扱う
- 記載がない・現金レシート → **役員立替**（private_account_item / 763260803）をデフォルトにする（この会社は社長1人のため、現金払いはほぼ役員の立替）。明らかに小口現金なら wallet 5502883

### 4. 登録内容を提示して登録

抽出結果を表で提示:

```
| 項目 | 読み取り結果 |
|---|---|
| 日付 | YYYY-MM-DD |
| 金額 | ¥X,XXX |
| 店名 | ... |
| 科目 | ...（ID） |
| 税区分 | ... |
| 支払方法 | 役員立替 等 |
```

ユーザーが画像とともに「経費にして」等の依頼をしている場合は**そのまま登録まで実行**し、結果とあわせて上表を報告する。画像だけが送られ意図が曖昧な場合は、表を見せて一言確認してから登録する。

登録は freee-expense と同じ `POST /api/1/deals`（description は「店名 品目」、`tag_ids: [35402337]` 必須）。

### 5. 完了報告

- 取引IDと確認URL `https://secure.freee.co.jp/deals#deal_id={id}` を提示
- **原本画像の保存を案内する**: この環境からはfreeeファイルボックスへの画像アップロードができない（Remote MCPの制限）。電子帳簿保存法対応のため、freeeモバイルアプリまたは https://secure.freee.co.jp/receipts から同じ画像をアップロードし、作成済みの取引に添付するよう毎回一言添える。

## 複数枚まとめて送られた場合

1枚ずつ抽出→全件まとめて一覧表で提示→一括登録→結果を一覧で報告。読めなかったものは表に「要再送」と記載する。
