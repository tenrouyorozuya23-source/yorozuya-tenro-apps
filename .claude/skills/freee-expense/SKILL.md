# freee 経費登録

事業所: 合同会社萬屋天狼（company_id: **10939384**）。
勘定科目ID・税区分・口座IDの一覧は `freee-accounting/references/company-master.md`（詳細は `account-items.tsv`）を参照。

方針: **経費にできるものは積極的に経費化する**。事業関連性が説明できる支出（機材・移動・打合せ・稽古/公演関連・制作外注・サブスク等）は適切な科目で登録する。事業関連性が疑わしいものだけユーザーに確認する。

## 入力の受け方

ユーザーが自由文で伝えてきたら、次のフォームに当てはめて解釈する。不足があれば**まとめて一度だけ**質問する（日付・金額・内容が最低限）。

```
【経費登録】
日付: YYYY-MM-DD
金額（税込）: 円
内容: 何を買った/使ったか
支払方法: 役員立替 / 現金 / freeeカード / PayPayデビット / GMOあおぞら / PayPay銀行 / 未払い
取引先: （わかれば）
```

## 登録手順

### 1. 科目・税区分を決める

company-master.md の「経費でよく使う科目」表から選ぶ。判断基準:
- デフォルトは各科目の税区分 **136**（課対仕入10%）
- 飲食料品（テイクアウト・弁当・スーパー）→ **163**（軽減8%）
- 領収書に登録番号（T+13桁）が無い個人・免税事業者への支払 → 経過措置: 〜2026-09-30 は **189**（軽8%は187）、2026-10-01以降は **190**（軽8%は188）
- 税金・保険・給与系 → **2**（対象外）

### 2. 支払方法 → payments を決める

| 支払方法 | from_walletable_type | from_walletable_id |
|---|---|---|
| **役員立替**（社長が個人財布で支払い） | `private_account_item` | **763260803**（役員借入金） |
| 現金（小口） | `wallet` | 5502883 |
| freeeカード Unlimited | `credit_card` | 2568791 |
| PayPay VISAデビット | `credit_card` | 1971666 |
| GMOあおぞら ***0456 | `bank_account` | 3496307 |
| PayPay銀行 ***9967 | `bank_account` | 3534782 |
| 未払い（後日支払う） | payments を付けない（未決済で作成） | — |

注意: 銀行口座・カード払いは自動同期で明細が入ってくることが多い。**同期対象口座の支払いは、まず手順4の未処理明細に該当がないか確認し、あれば明細側から処理して二重計上を防ぐ。**

### 3. 取引を作成

登録前に「日付・金額・科目・税区分・支払方法」を1行で提示し、ユーザーの依頼内容と齟齬がないことを確認してから実行（明示的な依頼があった場合は即実行してよい）:

```
freee_api_post { "service": "accounting", "path": "/api/1/deals", "body": {
  "company_id": 10939384,
  "issue_date": "YYYY-MM-DD",
  "type": "expense",
  "partner_id": <あれば>,
  "details": [{
    "account_item_id": <科目ID>,
    "tax_code": <税区分>,
    "amount": <税込金額>,
    "description": "<内容（店名・品目）>",
    "tag_ids": [35402337]
  }],
  "payments": [{ "amount": <金額>, "from_walletable_type": "<上表>", "from_walletable_id": <上表>, "date": "YYYY-MM-DD" }]
}}
```

- `tag_ids: [35402337]`（freee-mcpタグ）を必ず付ける
- 完了したら取引ID と確認URL `https://secure.freee.co.jp/deals#deal_id={id}` を提示

### 4. 未処理明細の一括経費化（「明細を処理して」と言われたら）

```
freee_api_get { "service": "accounting", "path": "/api/1/wallet_txns",
  "query": { "company_id": 10939384, "limit": 100 } }
```
- status=1（消込待ち）の明細を一覧化し、各明細の description から科目を推定して提案表（日付/摘要/金額/提案科目）を提示
- ユーザー承認後、出金明細は `POST /api/1/deals` で登録する。このとき payments の date・amount・口座を明細と一致させると自動で消し込まれる。入金明細で内容が売上なら type: "income"・売上高 763260719・税区分 129 で登録
- 判断がつかない明細は無理に登録せず「要確認」として残す

## 経費区分の早見表（迷ったら）

- 電車・タクシー・宿泊 → 旅費交通費 763260746
- 10万円未満の機材・道具 → 消耗品費 763260750（**10万円以上は固定資産の可能性 → ユーザーに確認**）
- 打合せのカフェ・食事 → 会議費 763260745 / 接待・手土産 → 交際費 763260744
- サブスク・サーバー・通信 → 通信費 763260747
- 出演料・制作委託の支払 → 外注費 763260741（**個人への支払は源泉徴収の可能性 → 金額が大きければ確認**）
- 印刷・宣伝 → 広告宣伝費 763260743
- スタジオ・スペース利用 → 地代家賃 763260758
- 手数料 → 支払手数料 763260756
- どうしても分類不能な少額 → 雑費 763260771（乱用しない）
