撮る順

  1. S1板付き：立ち位置に立った状態で始め、顔に明かりが入ったら正面を見る

    長さ 8秒 ・ カメラ 膝から上・固定（OBS の「膝から上」の枠に合わせる） ・ 目安 3 テイク

    点けるライト：背景（左）（40%）・背景（右）（40%）・顔のライト（60%）・輪郭のライト（30%）

    明かりの合図：背景と輪郭のライトは点けたまま。スタッフはスマホのライトのアプリで顔のライトを 0% にしておき、監督の「はい」で 2秒かけて 60% に上げる。カットの後、次のテイクの前に 0% に戻す。S1 が終わったら 60% に戻す

    OK の条件：正面を向いた後は、目線がカメラから外れない。体が揺れない

  2. S4カメラから見て右へ1歩（出演者から見ると左へ1歩・約60cm）動き、床の印の端で止まる

    長さ 6秒 ・ カメラ 膝から上・固定（OBS の「膝から上」の枠に合わせる） ・ 目安 2 テイク

    点けるライト：背景（左）（40%）・背景（右）（40%）・顔のライト（60%）・輪郭のライト（30%）

    OK の条件：床の印の範囲から足が出ない。止まってから 1 拍待つ

  3. シーンの間

  4. S2名前を言う（「灯守座、◯◯役の△△です」）

    長さ 5秒 ・ カメラ 胸から上・固定（OBS の「胸から上」の枠に合わせる） ・ 目安 3 テイク

    点けるライト：背景（左）（40%）・背景（右）（40%）・顔のライト（60%）・輪郭のライト（30%）

    OK の条件：言い間違えない。最後に 1 拍止まってから動く

  • ライトスタンドには必ず重りを乗せる（倒れるのが一番危ない）
