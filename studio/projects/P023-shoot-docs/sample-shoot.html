撮る順

  1. S1板付き：顔が暗いところから、明かりが入ったら正面を見る

    長さ 8秒 ・ カメラ 膝から上・固定 ・ 目安 3 テイク

    点けるライト：背景（左）（40%）・背景（右）（40%）・輪郭のライト（30%）・顔のライト（60%）

    明かりの合図：背景と輪郭のライトは点けたまま。スタッフが顔のライトを 0% にしておき、監督の「はい」で 2秒かけて 60% に上げる

    OK の条件：目線がカメラから外れない。体が揺れない

  2. S2名前を言う（「灯守座、◯◯役の△△です」）

    長さ 5秒 ・ カメラ 胸から上・固定 ・ 目安 3 テイク

    点けるライト：背景（左）（40%）・背景（右）（40%）・顔のライト（60%）・輪郭のライト（30%）

    OK の条件：言い間違えない。最後に 1 拍止まってから動く

  3. S3役の一言（台本の 1 行）

    長さ 6秒 ・ カメラ 胸から上・固定 ・ 目安 4 テイク

    点けるライト：背景（左）（40%）・背景（右）（40%）・顔のライト（60%）・輪郭のライト（30%）

    OK の条件：声の大きさが S2 とそろっている
