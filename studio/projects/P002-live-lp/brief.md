# P002 HPサンプル① 公演・ライブの製品ページ風LP — ブリーフ

- 目的: 舞台主宰・ライブ主催者に「公演を Apple の製品ページのように見せられる」ことを示すサンプル。発注の動機を作る
- 題材（架空）: 弾き語りライブ『夜光 — YAKŌ』Acoustic Night 2027（架空の出演者・会場。フッターとヒーロー下に「架空のサンプル」と明記）
- 合格ライン: Lighthouse モバイル Performance/Accessibility/SEO 90 以上、360px で崩れない、ファーストビューからチケット導線1タップ、別エージェント審査（apple-style-craft §4.4 と rubric の軸）で全軸7以上・平均7.5以上
- 公開: claude.ai のページ（管理アプリと同じ仕組み）＋ GitHub（Cloudflare は未設定）

## トリートメント3案
1. 【定番】写真風のライブ会場ヒーロー＋日程表 → テンプレっぽい。3Dを生かせない
2. 【製品】ギターを製品のように回して見せる → ギターの3D造形が難しく安っぽくなる危険
3. 【採用】**一本のマイクを「製品」として開示する**: 暗転の黒からリムライトの輪郭 → スポットが入る → カメラが回り込みグリルに寄る、をスクロールで進める。ライブの本質（声）を1つの物で語る。マイクは P016 の基盤を改良（グリルを高解像に）

## 構成（apple-style-craft §4.3 の型）
1. 板付きヒーロー: 黒、スポットのマイク（静止画）、見出し「夜光」、一言「一本のマイクと、ひとつの光」、ボタン「チケット」（1タップで #tickets）
2. 一行ずつ明るくなる文（3行）
3. 固定して進める連番（72枚・1080×1080 WebP、400vh）: 暗転 → 輪郭 → スポット → 回り込み → グリル
4. 大きな数字: 3公演 / 各回120席 / 約100分（架空の公演の仕様。実績ではない）
5. 日程とチケット（3公演、各回ボタン）
6. 静かな締め: 「その夜、声だけが光る」＋ボタン
- 色: 黒 #000 / #0b0b0c、文字 #f5f5f7 / #86868b、アクセント1色＝ハロゲンの琥珀 #f2b56b（ボタン）
- 書体: Noto Sans JP 300〜600（palt）、欧文 Inter 300/600
