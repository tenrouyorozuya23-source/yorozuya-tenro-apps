# S10-05 配信背景「楽屋の鏡」（架空のアイドルグループ・六花ノ灯）— 完成品（5.00）

- 等級: 完成品（審査1回目で 5.00、critical なし、数値ゲート合格。合格の下限ちょうど）
- 仕様: 30秒ループ・1920×1080・30fps・音なし。配信者を手前に立たせ、背景として流しっぱなしにする用途
- 演出:
  - 鏡の周りに電球、手前に化粧台と小物
  - 鏡は three の Reflector による本物の反射で、背後の吊りランプと衣装ラックが映る
  - 右上の電球だけが揺らぐ
  - 塵・カメラの微動・揺らぎはすべて周期30秒の整数倍で作ってある。圧縮前の画では継ぎ目の差が 0.171 で、通常の1コマ（0.125〜0.141）とほぼ同じ
- 制作メモ: この環境では反射のある 1080p が 1フレーム約4秒かかった。30秒を通しで書き出すと時間切れや再起動で2回失ったので、10秒ずつ分けて書き出してつないだ
- 次に直すなら:
  - 揺らぎを本当にかすかにする（弱まりを20%以下・30秒に2〜3回にし、暗いときは赤みを帯びさせる）
  - 電球をすりガラスの球にする
  - 鏡の角の四角いにじみを消す
  - グレインを入れ、10Mbps 以上で圧縮する
  - 1回で通して書き出し、I フレームを定期的に入れて、mp4 での継ぎ目の差（0.44）を下げる
