- 内容: ステージ中央のマイクに、トラスの8台のムービングヘッドが光を投げる
  - 1〜2小節: 光線が拍ごとに1本ずつ開く

  - 9.14〜9.375秒: 無音とブラックアウト
  - 9.375秒（HIT）: 光線がマイクの頭に収束する
  - 9.4秒〜: 公演の情報が出て、最後はアンバーのリムでホールド
- 次に直すなら（最終審査の指摘）:

  - HIT は細いビーム8本の先端を1点に集め、交点に白いフレアを3フレーム出す（今は柔らかい光の膜に見える）
  - エンドで黒いマイク本体が背景に溶け、頭だけ浮いて見える。本体に縁光を残す
  - 冒頭の金色の縁光をエンドで戻し、韻を踏ませる
  - 1.8秒付近の四角いフレアを円形に作り直し、接写→広角をマッチカットにする
  - 6秒バンパーは 8.9〜14.9秒で切り出し、無音→HIT を頭に置く
