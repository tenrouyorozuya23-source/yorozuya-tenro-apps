# S09-06 記事連動ショート「暗転の一拍」— 完成品（5.71）

- 等級: 完成品。審査1回目で 5.71。critical はなく、数値ゲートも合格
- 仕様: 20秒・1080×1920・30fps・-14.1 LUFS・TP -2.5。音楽は自作（120BPM・Dm）
- 演出: 同じカット（暗い舞台の椅子にスポットが灯る）を3回見せる
  - 1回目「間なし」: 3.0秒に点灯
  - 2回目「一拍」: 0.5秒の暗転のあと 9.0秒に点灯
  - 3回目「二拍」: 1.0秒の暗転のあと 15.0秒に点灯
  - 暗転は映像と音で同時に入れ、音はデジタル無音にした。点灯は鐘と同時（±5ms）
  - 最後に「間が 緊張をつくる」と出す
- 次に直すなら:
  - 暗転の前の待ちと、点灯後に光を保つ長さを3回で揃え、本当に「暗転の長さだけ」が違うようにする
  - 区間の切り替えを溶暗（光をゆっくり落とす）と L カット（音を次の画に少し残す）にし、点灯を3フレームで立ち上げる
  - 主役を S09-02 と同じ箱の椅子から変える
