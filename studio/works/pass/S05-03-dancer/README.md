# S05-03 ダンサー 公式サイト「九条 舞」（架空）— 完成品（5.67）

- 等級: 完成品（審査1回目 5.67・判定 publish。critical なし、Web の数値ゲートも合格）
- 公開（Artifact）: https://claude.ai/artifact/7ztqo8DF4ZE2BNeXovCpVh
- 本体: `studio/projects/S05-03-dancer/site/`（data.js と明朝のサブセットは build.py が facts.json から生成）
- 内容: 手首と足首に付けた灯りの長時間露光のように、4本の光の線（右手首・左手首・右足首・左足首）が 0.25 秒ずつずれて描かれ、それぞれの線の終わりに「作品／出演歴／ワークショップ／ご依頼」の入口が立つ
  - 線の終わりは画面の位置（NDC）から逆算して置くので、スマホでも PC でも入口が画面の中に並ぶ
  - 入口にホバー／フォーカスすると、その線だけが明るく、ほかは沈む
  - 結びのフッターに、右手首の線を署名のように小さく描いて冒頭と韻を踏む
- 審査のあとに直したこと: 描き終わる前の見えない入口に Tab で触れられた → 描き終わるまで tabindex=-1・pointer-events:none
- 次に直すなら（審査の指摘）:
  - 描いている間だけ、線を引く人型（細い棒の骨格、IK で手首・足首に付ける）を見せ、描き終わったら消す（「人型の動き」を見せる）
  - 足首の線が名前「九条 舞」を横切る → キャプションの範囲の線を薄くするマスク、線の位置をずらす
  - 手は速く、足は重く（描く時間とカーブを変える）
  - 長時間露光らしい太さ・明るさのムラと、ゆっくりした呼吸
  - 各節の見出しに、その肢の線の小片を描く
