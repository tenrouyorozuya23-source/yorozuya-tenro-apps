# S07-09 3D 製品 LP「ORVANE ONE」（架空の Orvane Acoustics）— 完成品（5.83）

- 等級: 完成品（審査2回目・最終 5.83。critical なし、320〜1440px で崩れ・エラーなし）
- 7軸: スタイル 6／発想 6／動き 6／デザイン・文字 6／仕上げ 5／技術 6（音は Web のため対象外）
- 公開: https://claude.ai/artifact/BfS43gMt9PMUKvnwgk5169
- ソース: `studio/projects/S07-09-orvane/`（facts.json → build.py → site/）
- ブランド名: 当初の案「Sirius Acoustics」は、実在の製品名（Naga Audio Sirius など）と重なるため変えた
- 内容: ガラスの筒の 360° スピーカーを three.js で組み、スクロールの位置で姿を補間する。1段に1つの特長を大きな文字で出す
  - 段: トップ → 360°（俯瞰で音の輪）→ 3（分解とドライバー名）→ ガラス（寄り）→ 20時間（20本のゲージ）→ 1.4kg（上から順に落ちて組み上がり、筒が被さって光の輪が脈打つ）→ 色と価格
  - 映り込み用に、左右の縦長ストリップライトだけの部屋を PMREM で作った。ガラスと金属の縁に縦のハイライトが立つ
- 審査1回目（5.17）からの直し:
  - ガラスが黒い樹脂に見えたので、環境と材質を作り直した
  - 組み上げの段を足した
  - 分解を画面に収め、床に沈まないようにした
  - 縦長の画面で文字と製品を分けた
  - 大きな文字を、幕が開くように出す
  - 320px のヘッダーを直した
  - 制作メモを配信しないようにした
- 次に直すなら（最終審査の指摘）:
  - 分解の最大を後半の組み上げの段に移し、分解→組み上げを1本の見せ場にする
  - 段のあいだで2段分のコピーが同時に見えないよう、常に1段だけ点灯させる
  - 「霧」を選んでも本体が暗いまま。金属感を下げ、明るい色にする
  - ストリップの映り込みが柱のようにベタ塗りで見える。細くして、ぼかした2本目を足す
  - スマホでは製品を大きく。仕様の段では描画を止める
