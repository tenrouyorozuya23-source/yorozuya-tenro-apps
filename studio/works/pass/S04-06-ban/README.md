# S04-06 新譜リリース告知「盤」（架空の凪野ソラ『凪の朝』）— 完成品（5.14）

- 等級: 完成品（審査1回目 5.14・判定 publish。critical なし、数値ゲート合格。下限すれすれ）
- 仕様: 15秒・1080×1920・30fps・BT.709・-14.2 LUFS・TP -2.0 dBTP。音楽は自作の合成（96BPM・E、歌なし、6小節＝15秒）
- 内容: ガラスのケースに立てた盤がゆっくり回り、ストリップライトの光の帯が表面を撫でる
  - 0〜4.5秒: 溝とラベルのマクロ。帯が画面を横切り続ける
  - 4.5〜9秒: 引いて正面へ
  - 8.6〜10.0秒: 最後の帯がケースの前面を左から右へ渡り、刷られた題『凪の朝』を読ませ、10.0秒（小節頭のインパクト）で読み終える
  - 10〜15秒: 凪野ソラ / NEW SINGLE / 2027.1.20 配信開始 / ※架空のアーティスト・作品です
- 技術: ストリップライトを映り込み用の環境（PMREM）に入れ、盤とガラスに本物の反射として光の帯を出す。環境は位置と明るさを刻んでキャッシュ
- 次に直すなら（審査の指摘）:
  - 題は 9.4 秒まで完全に見せず、帯が通った所から1字ずつ光らせて 10.0 秒で「朝」を点灯（ヒーローの瞬間）
  - 9.69〜10.0 秒に本当の無音（半拍）を入れてインパクトを立てる。帯の通過に whoosh、着地に tick
  - ガラスの屈折と分散、ケースの分解→スナップ（スタイル4のシグネチャ）
  - フレーム0から完成した明るい絵（フェードインをやめる）
  - エンド画：盤のリムライト、ケースの枠を閉じる、画面下の青いぼけ（リムライトの床反射）を消す、冒頭の帯で韻を踏む
  - カメラ経路を S07-05 と変える（真上からのティルトなど）
