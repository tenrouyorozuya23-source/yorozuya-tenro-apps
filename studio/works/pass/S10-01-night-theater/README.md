# S10-01 配信背景「深夜の劇場」— 完成品（5.50）

- 等級: 完成品
  - 1回目の審査は 4.67（合格未満、fix）
  - 指摘を1ラウンドでまとめて直し、新しい審査員が採点して 5.50。critical なし、数値ゲートも合格
- 仕様: 30秒ループ・1920×1080・30fps・音なし（12MB）
- 内容: 誰もいない劇場の客席と、舞台の右寄りに残るゴーストライト（金網のケージの裸電球）。電球のまわりに光の筋と3層のハゼが漂う
  - すべての動き（カメラ・ハゼ・電球のかすかな弱まり・光の筋）は周期 30 秒の整数倍で作った。光の筋は、時刻を 30 秒ずらした2本を重ねて入れ替える
  - ループの継ぎ目: レンダラーの出力（PNG）では、最終フレーム→先頭フレームの差が隣り合うフレームの差と同じ（seam_check.json）
- 1回目の審査のあとに直したこと:
  - 一灯を画面中央から右へ移した
  - 縁の硬いグローをやめ、金網のケージと光の筋にした
  - 星空のように見えたハゼを、光の中だけで明るい柔らかい3層の点にした
  - 客席の赤を暗くした
  - 各ワーカーの最初の1枚を空描きにして、分割の境目の跳ねをなくした
- 次に直すなら（2回目の審査より）:
  - 一灯が配信者の肩・頭の位置に重なる。右三分線（x≈1450〜1520）まで寄せ、電球を大きく見せる
  - 電球から立つ筋が煙に見える。空気全体を満たす体積フォグにする
  - 奥の壁にバンディングがある。16bit で描きディザを入れる。PNG 連番から1回で通しエンコードし、I フレームの毎秒の脈動をなくす
  - 床と壁の光の中心が電球からずれている
  - 座席をモデル化する（背の曲面・肘掛け）
