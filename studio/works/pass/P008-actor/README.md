# P008 俳優のポートフォリオ（架空の汐見 蓮司）— 完成品（6.0）

- 等級: 完成品（審査2回目・最終 6.0。critical なし、ゲートはすべて yes か対象外。320〜1440px で横スクロールなし）
- 7軸: スタイル 6／発想 6／動き 6／デザイン・文字 6／仕上げ 5／技術 7（音は Web のため対象外）
- 公開: https://claude.ai/artifact/UtJfNsiwwkWt269LfyJhzJ
- ソース: `studio/projects/P008-actor/`（facts.json → build.py → site/）
- 内容: 写真の素材がないので、横顔の立体を three.js で組み、照明だけで「役の幅」を見せる
  - 立体は、前・後ろの輪郭と左右の幅から、高さごとの楕円の断面で作る。鼻と唇の凹凸は顔の中央だけに付ける
  - 冒頭は映画のタイトルバック。シネスコの黒帯の中、逆光の輪郭が立ち上がる。4行のクレジットは出方を変えている
  - 「光の習作」は、6つの照明（逆光・レンブラント・スプリット・下からの光・窓の光・ピンスポット）。19秒のリールとして通しで見られる
  - 出演歴は、映画のクレジットの組み
  - 料金の目安は、320px でも横スクロールしない。問い合わせフォームは見本で、送信しない
  - 終わりは、同じ横顔に真上のピンスポットが点くエンドクレジットで、冒頭と対にした
- 審査1回目（5.67）からの直し:
  - 面の巻き方が逆で、影の normalBias で頭全体が自分の影に入っていた。巻き方を直した
  - 目のくぼみと眉を足した
  - 冒頭の文字の出方を変え、エンドクレジットとリールを足した
  - WebGL が使えないときのために、照明ごとの静止画を用意した
- 次に直すなら（最終審査の指摘）:
  - 頭がマネキンに見える。鼻と顎の張り出しを強め、冒頭のカメラを横顔の輪郭にリムが乗る角度に回す。壁に落ちる影の横顔を主役にする案もある
  - エンドのピンスポットで、顔に影の帯が出る
  - リールの各シーンを出演歴の役と結び付ける
  - 狭い幅での括弧の泣き別れと、照明の名前の途中の改行
  - タイムコードはリールの経過時間で出す
  - 下からの光のリムを紫から外す
