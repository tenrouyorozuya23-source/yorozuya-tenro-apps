# S01-01『硝子の庭』ティザー第1弾「一灯」（架空の劇団・灯守座）— 完成品（5.86）

- 等級: 完成品。1回目の審査は 5.29 で合格未満だった。計画にない劇団名の行を出していて、その回数がシリーズの設定と食い違い、critical になった。修正後に新しい審査員が採点し、5.86。critical はなく、数値ゲートも合格
- 15秒・1080×1920・30fps・-14.1 LUFS・TP -2.6。音楽は自作の TNR-B06「暗転」15秒版（S08-03）
- 演出: 0秒から光の点が見えていて、椅子の真上まで降りる。8.9秒に細い光の糸が垂れ、9〜10秒は無音に合わせて暗転する。10.0秒の鐘と同時に、光の点の位置から空の椅子へスポットが1フレームで灯り、「硝子の庭／解禁 12.1」が出る
- 次に直すなら:
  - 塵を丸いぼけた粒にし、影の中では暗くする。グレインを足し、光の点の輪のふちをなくす
  - 0秒目の映り込みを消して、主役を光の点1つにする。光の点の脈動の山を拍の頭（cos）に合わせる
  - ライザーの山を暗転の直前に置き、鐘の吸い込みで J カットを入れる。カメラにピント送りを足す
