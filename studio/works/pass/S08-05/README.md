# S08-05 合成 BGM「間」TNR-B09（箏と無音の間・60秒）— 完成品（5.71）

- 等級: 完成品。審査1回目で 5.71、critical なし、数値ゲート合格。
- 仕様: 60秒、60BPM（1拍＝30フレーム）、D の都節。m4a は -14.1 LUFS／TP -2.1。
- 音: 箏（Karplus–Strong）の旋律と、薄い swell の2層だけ。
  - 16〜20秒と38〜42秒をデジタル無音にした。
  - 42.0秒（70%）の無音明けに、高い D6・チャイム・低い一打を入れた。
  - 49〜53秒で冒頭の動機に戻って終わる。
- 用途: 和の工芸・旅館・時代劇の短尺。
- 次に直すなら:
  - 箏の遅延線を小数長にして、上の音域の音程のずれ（+24〜+32c）を直す。
  - 50秒の押し手を音階の中に着地させる。
  - 無音への入りを、ばっさり切らずに余韻で消す。
  - 終わりを自然な減衰にする。
