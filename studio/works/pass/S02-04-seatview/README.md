- 内容:
  - 座席表（SVG）、列と番号のセレクト、左右ボタン、座席表の矢印キーで席を選ぶ
  - 選ぶと、その席の目の高さへカメラが弧を描いて移り、舞台の見え方を three.js で出す
  - 座席は1階 12列×18席と2階 3列×16席。列ごとに半席ずらしている
- 計算（facts.json の模型の寸法から）:
  - 舞台の前の縁までの距離と、舞台の中央への角度
  - 目の高さと舞台の床の差
  - 前の人の頭・首・肩（3列前まで）、2階の手すり、ひさしが視線をさえぎるかを、線分どうしの距離で判定する
  - 判定の結果から「舞台の床の中央がどこから見えるか」「役者の顔（前・中央・奥）が見えるか」「ひさしで舞台の口の上が何 m 隠れるか」を文で出す
- 審査1回目（5.5）の critical: 2列前の真正面の人を見ていなかった。3D の線分判定に作り直した。ひさしの下の天井高が 1.35m しかない模型の破綻も直した
- 公開前の直し: 注記を「床から 1.15m（座った姿勢）」に直した。poster.jpg の焼き込みの文字も取った
- 次に直すなら（最終審査の指摘）:
  - 3D の舞台の前の縁を計算と同じ z=0・幅 10m にそろえる（今は絵が 0.7m 手前）
  - ひさしで隠れる範囲の帯が、ひさし自身に隠れて見えない。depthTest を切って重ねる
  - 床と顔の判定を面（21×17 点・9 点）で行い、「床の◯%が見える」と出す。理由は多い方から書く
