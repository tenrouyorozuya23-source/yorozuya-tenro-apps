# S02-08 チケット LP の A/B 2案と計測設計『冬の灯』（架空）— 完成品（5.50）

- 等級: 完成品（審査1回目 5.50・判定 publish。critical なし、Web の数値ゲートも合格。必要人数の式は審査員が手計算で一致を確認）
- 公開（Artifact）: https://claude.ai/artifact/D2vbv1xTBvxjjzvBG9mXq6
- 本体: `studio/projects/S02-08-ab-lp/site/`（data.js と明朝のサブセットは build.py が facts.json から生成）
- 内容: 架空の灯守座『冬の灯』のチケット LP。上の帯で見本の2案を切り替えられる
  - A：客席の灯りが、売れた席から順に消えていく動画（S09-07 残席ショートの客席を文字なしで 720×1280・9秒に描き直し、`projects/S09-07-zanseki/zanseki_bg.html`）
  - B：その最後のフレームの静止画（A は 9 秒で B と同じ絵に着地する）
  - 計測の設計：比べるもの・割り当て（50/50、端末に覚える）・主な指標（予約ボタン #buy の到達率。ヒーローのボタンは数えない）・副の指標・判定の条件、送るイベントの表、必要人数の計算機（2つの割合の差の検定、両側 α=0.05・検出力 80%）、このページで今送ったイベントの一覧（window.dataLayer、外部には送らない）
- 審査のあとに直したこと:
  - cta_visible が 2 回送られていた（IntersectionObserver のしきい値 2 つでタイマーを上書き）→ しきい値を 0.5 だけにし、タイマーを1つに
  - 主な指標をどのボタンで数えるか書いていなかった → 予約ボタン（#buy）だけと明記
  - 見本の帯で切り替えたとき、数え直されなかった → 監視を張り直し、ab_preview_switch を別に送る
  - イベント名が語の途中で折れていた、計算機が範囲外の入力を黙って丸めていた、reduced-motion で動画を再生できなかった → それぞれ直した
- 次に直すなら（審査の指摘）:
  - A の動画を「B と同じ絵から始まり、一度全席が灯り直して、売れた順に消えて B に戻る」構成にして、比べる差を「動き」だけにする（今は A の冒頭が『空いている』絵で、希少性の量が交絡している）
  - 消灯の間隔を ease-in にして、最後の数灯に溜めを作る
  - PC のファーストビューの釣り合い（絵の切り取りと文字の位置）
