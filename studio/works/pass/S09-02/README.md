# S09-02 記事連動ショート「色温度で印象はこう変わる」— 完成品（5.71）

- 等級: 完成品
  - 1回目の審査は 5.29（完成品）。ただし 5600K を「昼光色」と表記していて不正確だった（JIS の区分では昼光色は 5700〜7100K）
  - 表記を直して新しい審査員が採点し 5.71。critical はなく、数値ゲートも合格
- 仕様: 20秒・1080×1920・30fps・-14.2 LUFS・TP -2.3。音楽は自作の 120BPM（A メジャー）で、12〜13秒はデジタル無音
- 演出: 同じ椅子を 0〜6秒は 3200K（タングステン）、6.0秒の鐘で 5600K（デイライト）に照らし替える。無音の暗転のあと、13.0秒の一打で左から 3200K、半拍あとに右から 5600K を当て、「色温度で 物語が変わる」と見せる
- S01-01 と同じ椅子のモデルを使っている
- 次に直すなら:
  - ピント送りを、絞りの変化ではなく焦点距離を動かして見えるようにする
  - 5600K でも木の色が残る明るさにし、背もたれの影の漏れ（shadow.bias）を消す
  - 18.0秒のスタブに補足文を合わせ、寒色の点灯にも音を付ける
