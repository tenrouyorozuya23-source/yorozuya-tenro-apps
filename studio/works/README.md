# 完成品の保存先

2026-11-06 から、すべての制作を完成まで作り、別エージェントの審査の等級で分けて保存する（rubric.md §4.2）。

| フォルダ | 等級 | 条件 |
|---|---|---|
| `pass/<ID>/` | 一級・完成品 | 完成品＝平均 5.0 以上・critical なし・数値ゲート（音量・黒味・静止・安全域・可読時間）合格。一級＝全軸 7 以上・平均 7.5 以上・ゲートすべて yes（ユーザー決定 2026-11-06） |
| `below/<ID>/` | 合格未満 | それ以外。記録として保存する |
| `tools/<ID>/` | 道具 | 社内の道具。審査の対象外 |

各フォルダに、成果物・審査結果（review.json）・README（点数と学び）を置く。管理アプリの works にも grade と score を記録する。
`P001/`・`P016/`・`P028/` は、この運用を始める前の成果物。
