# S08-04 合成 BGM「客電」TNR-B08（客入れ用 3分ループ）— 合格未満（5.00）

- 等級: 合格未満
  - 1回目の審査は 4.60。ベースの音切れとクリックが約80回あり、8小節ごとの段差が 8 LU あった。
  - 2回目は新しい審査員で、平均 5.00、critical なし。ただし数値ゲートで不合格になった。m4a の継ぎ目に AAC の末尾の余白とクリックが残り、loop_seam を満たさなかった。
- 仕様: 180.000 秒・80BPM・E メジャー・ドラムなし。wav は -14.1 LUFS／-2.8 dBTP、m4a は -14.1／-2.6。短期ラウドネスの幅は 3.9 LU。
- 良いところ: 話し声の帯域（1〜4kHz）が全体比 -15dB と低く、客入れで会話を邪魔しにくい。wav の継ぎ目は、普通の小節頭と区別がつかない。
- ループで使うときは **wav を使う**。m4a は試聴用で、ループ再生には向かない。
- 残っている欠陥:
  - bgm.py のベースは音の終わりに減衰がなく、6kHz 以上のクリックが 85 回ある。
  - 同じ音程を重ねる小節で、ベース帯域が 0.19 秒だけ 14dB 落ちる。
  - A の和音の小節は、低域と中域の差が最大 +6.8dB。
- 次に直すなら:
  - bgm.py の bass_note に 40ms の減衰を付け、重なりは1音につなぐ。
  - m4a を2周分（360 秒＝AAC 16,875 フレーム）で書き出し、継ぎ目に余白を作らない。
  - A の小節のベースを1オクターブ上げる。
