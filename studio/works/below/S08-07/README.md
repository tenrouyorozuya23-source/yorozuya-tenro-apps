# S08-07 BGM ライブラリ Web プレイヤー — 合格未満（5.00）

- 等級: 合格未満
  - 1回目の審査は 5.00 だったが、波形の未再生バーのコントラストが 2.10:1 で、数値ゲートに通らなかった。
  - 2回目は新しい審査員が 5.00 をつけた。直した版で、表示文字列を使って曲を探す処理が壊れ、画面幅が変わるたびに JS エラーが出た。これが critical となり、数値ゲートにも通らなかった。
- 本体: `studio/projects/S08-07-library-player/site/`（1ページ）
- 公開: https://raw.githack.com/tenrouyorozuya23-source/yorozuya-tenro-apps/studio-autopilot/studio/projects/S08-07-library-player/site/index.html
- 内容:
  - 自作 BGM 7曲（B01〜B06、B09）を、ムード・テンポ・尺で絞り込める。
  - 6／15／30／60秒のカットを切り替えられる。波形を押すと、その位置から再生する。
  - 再生中の曲は URL のハッシュで共有できる。
  - 音源は、社の楽曲（公開は許可制）ではなく自作の合成 BGM に置き換えた。
- 審査のあとに直した不具合: 曲の特定を `data-id` に変え、画面幅の変化で出ていたエラーを解消した。B09 の共有もここで直り、ハッシュで開いたときの波形も選んだカットに合うようにした。
- 次に直すなら:
  - 複数の曲をまとめて共有できる「提案リスト」を作る（顧客への提案に使う、という計画の芯）。
  - スマホの絞り込みで、横に送れることが分かる手がかりを付ける。
  - B05_30s のピークを -1 dBTP 以下にする。
