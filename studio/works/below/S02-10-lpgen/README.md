# S02-10 公演 LP ジェネレータ（社内用の道具・見本）— 合格未満（5.5）

- 等級: 合格未満（審査2回目・最終 5.5。critical はないが、ゲートの safe_area が no）
  - OGP 画像では、長い題が最小の 40px まで縮んでも右の余白 80px を越える
  - PC 1440×900 では、JSON のエラー表示が画面の外に出る
- 7軸: スタイル 6／発想 5／動き 5／デザイン・文字 6／仕上げ 6／技術 5（音は Web のため対象外）
- 公開: https://claude.ai/artifact/UUBh4PFZgNu5aCEPW5NhFi
- ソース: `studio/projects/S02-10-lpgen/`（facts.json → build.py → site/）
- 内容: 公演の情報を JSON で書くと、検証して、LP（単体で開ける HTML）と OGP 画像（1200×630）を作り、保存できる
  - 見た目は夜・紙・白の3つ
  - 曜日は日付から計算する。年をまたぐ公演は、終わりの日にも年を付ける
  - 差し色と背景の明暗比を確かめる
  - 明朝体は、使う字（英数字を含む）だけを読み込む
  - url を書くと og:url と og:image を入れる
  - 下書きを端末に残し、JSON の保存と読み込みができる
- 審査1回目（5.0）の critical: 英字の題が別の書体になった（明朝のサブセットに英字がなかった）。2回目までに直した
- 次に直すなら（最終審査の指摘）:
  - OGP: 題は3行まで、最小 56px にする。それでも入らなければエラーにして短い題（og_title）を書いてもらう。行は語の区切りで分け、注記は切らずに2行にする
  - PC: エラーを textarea の上に固定して出し、プレビューにも「エラーのため前の内容」の帯を出す
  - url の末尾に / がないときの og:image のパスを直す。og:image の幅・高さ・alt と canonical も出す
  - JSON を開いたあと・見た目を変えたあとも、下書きを保存する
  - 文字であるべき項目の型を確かめる。読みは h1 の外に出す
  - update() の非同期の順序（保存ボタンは描き終わるまで押せないようにする）
