# S03-08 生誕祭カード（架空の人物「凪野 ソラ」）— 合格未満（5.71）

- 等級: 合格未満。審査 1回目 5.71 → 修正後（新しい審査員）5.71
- 8秒・1080×1920・30fps・-14 LUFS。音楽は自作（72BPM・オルゴール風エレピ、吹き消しの直後に本当の無音、日付で鈴）
- 演出: 一本の蝋燭の灯が縦組みの名前を照らす → 5.0秒（拍）で吹き消し → 煙と余熱の中で日付が残る
- 減点の中心: 蝋燭が素の円柱（溶けた縁・半透明感がない）、消灯後に上面が光る、煙が1本線で等速、カメラ操作が1種
- 型: `studio/projects/S03-08-birthday-card/card.html` に `{"name","date","sub"}` を渡せば別の人の版を作れる
