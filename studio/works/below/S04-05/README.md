# S04-05 フェス出演者ラインナップ（架空の「灯籠フェス 2027」）— 合格未満（4.29）

- 等級: 合格未満。審査 1回目 4.00 → 修正後（新しい審査員）4.29。どちらも安全域の外に文字が出て critical
- 30秒・1080×1920・30fps・-14.3 LUFS・TP -2.1。音楽は自作 TNR-B01（コーポレート 120BPM）の30秒版
- 演出: 舞台の上に吊った LED バトンに出演者名が2秒ごとに灯る。20.0秒のインパクトでヘッドライナー、最後に全体へ引いてフェス名と日程
- 減点の中心: 縦に長いリストをスクロールすると、上の行が安全域（上260px）の外へ出る。バトンが平面の白線で3Dの素材感がない。点灯のイーズ（0.12秒）が拍から4フレーム遅れと判定された
- 学び: 縦に積む構成は9:16 では安全域を超えやすい。行数が多いときは「灯った行だけを見せて前の行は画面外へ」ではなく、全体が常に 260〜1500 に収まる大きさで組む。点灯は1フレームで拍に合わせる（S03-06 と同じ）
