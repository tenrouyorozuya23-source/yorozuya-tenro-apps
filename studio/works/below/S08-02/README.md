# S08-02 合成 BGM「開場」TNR-B07（明るいコーポレート系 60/30/15/6秒＋1:1 ジャケット）— 合格未満（5.29）

- 等級: 合格未満。
  - 1回目 4.86: 既存曲 B01 と骨格が同じで、抑揚も 2.3dB しかなかった。
  - 2回目 5.29（新しい審査員）: 平均は 5.0 以上で critical もない。ただし 6秒版の低域−中域が +6.43dB で、数値ゲート（+6dB 以下）に通らなかった。
- 原因: 曲生成ツール `bgm_pack.py` の帯域測定 `bands()` が、全体に Hann 窓をかけていたため約 2.5dB 低く出て、見逃していた。この回で Welch 法に直した。次からは自動補正（低域を下げるイコライザー）が正しく効く。
- 音: 120BPM、F メジャー。
  - 主旋律は F5→C6 の 5度の跳躍から下りる形。終止は IV→I（Bbmaj7→F）。
  - 60秒版の流れ: 0秒に一打 → 4〜12秒はキックなし → 20.0秒の無音明けにリード → 42.0秒（70%）の無音明けが山場。区間ごとの音量差は -22〜-11.6 LUFS、LRA 8.6。
- 実測（m4a）: 60s は -14.1 LUFS / TP -3.0、30s は -14.2 / -2.6、15s は -14.1 / -2.9、6s は -14.0 / -3.7。
- ジャケット: 暗いロビーで両開きの扉が細く開き、暖かい光が床に伸びる。文字は左上に置いた。
- 次に直すなら:
  - 6秒版の低域を 1dB 下げる。
  - ライザーの終わりを無音の頭に合わせる。
  - 旋律を「問いと答え」にして、拍の頭のぶつかり（26/34/48秒）を和音の音に替える。
  - 扉の隙間の光にスモークの筋を入れる。
