# S03-06 アイドル・メンバーカラー紹介（架空のグループ「六花ノ灯」6人）— 合格未満（5.71）

- 等級: 合格未満。審査 1回目 4.86（rework）→ 修正後（新しい審査員）5.71
- 15秒・1080×1920・30fps・-14.2 LUFS。音楽は自作 TNR-B05（Future bass 160BPM）の15秒版
- 演出: 冒頭は題字と白いスポット → 1.5秒ごとに1人ずつ、その人の色のスポットが拍で灯り、カメラが横に移る → 最後に引いて6色が半拍ずつ灯り、題字
- 減点の中心: 6色が揃う見せ場が遅い（75〜90%）、1人1.5秒では名前を読む時間が足りない、入り方が全員同じ、締めで名前が小さい
- 学び: 6人×15秒は詰めすぎ。1人1.8秒以上を守るなら、6人は20秒以上か、2人ずつ見せる
