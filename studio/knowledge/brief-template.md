## 記入例: 萬屋天狼 15秒 SNS 広告（縦）

### 0. 管理
- 計画ID / 版: P0xx-v1（例）　　作成日: 2026-11-05　　notes: なし（例のため）

### 1. 目的と納品
- 視聴者: X・Instagram のフィードをスマホで流し見している、小規模事業者・イベント主催者。音なしで見る人が多い。
- 伝えたいこと1つ: 映像・音・配信・Web を、萬屋天狼にまとめて頼める。
- CTA: 制作の相談（プロフィールのリンクから）。
- 掲載先 / 尺 / 画面比 / 解像度 / fps / 言語: X・Instagram リール / 15.000 秒 / 9:16 / 1080×1920 / 30fps（450f）/ 日本語（社名の欧文表記だけ英字）。
- 納品物: final.mp4（マスター CRF 17）、配信用 mp4、poster.jpg（13.9 秒のフレーム）、music-only.wav、ソース一式。
- 正確に出すもの: 社名「萬屋天狼」「YOROZUYA TENRO」、4つの事業の呼び方（facts.json）。

### 2. inputs
| 項目 | 内容 |
|---|---|
| ブランド名・ロゴ | 合同会社萬屋天狼。ロゴデータなし → 明朝のワードマーク＋天狼星の光点 |
| 色 | 夜藍 #0E1430 / 藍 #1B2350 / 星白 #F4EEDF / 灰青 #6B7699 / 灯金 #F2B544（アクセント） |
| 書体 | Shippori Mincho B1 800（社名・見出し。和の格）／Zen Kaku Gothic New 500（小見出し。小さくても読める）。どちらも OFL |
| 事実・数字 | facts.json（下記）。実績件数・顧客数などの数字は出さない |
| 素材 | なし。すべてコードで描く |
| 音楽 | 合成 BGM（§5） |

facts.json:
```json
{
  "company_ja": "萬屋天狼",
  "company_en": "YOROZUYA TENRO",
  "services": [
    {"key": "video", "label": "映像", "sub": "撮影・編集"},
    {"key": "sound", "label": "音", "sub": "作曲・効果音"},
    {"key": "live",  "label": "配信", "sub": "ライブ・収録"},
    {"key": "web",   "label": "Web", "sub": "サイト制作"}
  ],
  "cta": "制作のご相談|受付中",
  "cta_sub": "プロフィールのリンクから",
  "_source": "事業内容はユーザー確認済みの範囲で記載（呼び方は要確認）"
}
```

### 3. direction
- コンセプト1行: **天狼星の光の線が、4つの仕事を一筆で描き、最後にひとつの星座になる。**
- スタイル: 天狼ナイト（当社ハウス）× ライン・アート（`styles.md`）。不変条件: 線は1本で途切れない／発光するのは灯金と星だけ／地は夜藍で純黒にしない／動きは「速く着いて柔らかく止まる」。
- パレット: 地 #0E1430 70% / 面 #1B2350 15% / 文字 #F4EEDF / 補助線 #6B7699 / アクセント #F2B544 10% 以下（星・線の先端・キーワードのブロックだけ）。
- 書体: 見出し Shippori Mincho B1 800（字間 0.04em）／小見出し Zen Kaku Gothic New 500（字間 0.12em、#6B7699）。
- カメラの語彙: スロープッシュ（各小節 1.00→1.04。止まって見せない）／ホイップ（小節1→2、星が場面を運ぶ。ブラー N=8）／プルバック（小節6、対数ズーム 1.0→0.38。全体を明かす）。この3つだけ。
- 光: 天狼星が唯一の光源。加算合成の放射グラデーション＋回折スパイク（R001）。ブルームは灯金だけ。
- 禁止: `playbook.md` §3.5 ＋ 流れ星の量産、キラキラのパーティクル、星空の壁紙、虹色のグラデ、句点。

### 4. トリートメント
| 案 | ログライン | フック | ヒーロー | 結末の韻 |
|---|---|---|---|---|
| A 一筆の星 | 星の光の線が、映像の枠→音の波形→配信の灯→Web の窓を一筆で描き、4つが星座になる | フレーム0で星が燃え、キーワードが拍で着地 | 9.375 秒、4つの図形が星になり、線で結ばれて星座に | 冒頭と同じ位置で星がまたたき、社名が下に着地 |
| B 灯りの町 | 夜の町の窓明かりが1つずつ点き、窓の中で4つの仕事が見える | 真っ暗な町に最初の窓が点く | 町じゅうの灯りが一斉に点く | 灯りが空へ昇って星になる |
| C 開演 | 舞台の幕が開くと、撮影・音響・配信・Web が一つの公演を作っている | 幕の隙間から光が漏れる | 幕が全開、照明が点く | 幕が閉じ、社名が緞帳に浮かぶ |
- 採用: **A**。理由: ブランドの象徴（天狼星）が主役で、1本の線がすべての転換を運ぶのでクロスフェードが要らない。音なしでも4つの仕事が読める。Canvas2D の線と光だけで作れ、既存の道具で品質を詰めやすい。B は窓の中が 9:16 のサムネイルでは小さすぎて読めない。C は人物・舞台の作画が重く、15 秒では説明が増える。
- A の自覚しているクリシェ: 「星がきらめいてロゴ」。→ 光らせるのは1点だけにし、きらめきの量ではなく「線が意味のある形を描く」ことで差をつける。
- 起承転結: 起＝星が燃える（フック）／承＝線が4つの仕事を順に描く／転＝無音のあと、4つが星になって結ばれる／結＝相談の呼びかけ、社名。
- ネイティブムーブ: 4つの図形が同じ線のまま星に縮み、16分音符ごとに1本ずつ結ばれて星座になる。
- 参考: 一筆書き・ライン系の構図とペース、線の先端に光を置く手法を学ぶ。他社のロゴ・旋律・ショットは取らない。

### 5. 音楽
- 選択: **合成 BGM**。理由: 尺 15.000 秒ちょうどが必要、星の明るさに合う澄んだ音色にしたい、サウンドロゴを作りたい。
- 合成: 128 BPM × 8 小節 = 15.0 秒（R001 の型）。キー D minor、進行 Dm–B♭–F–C を循環し、ロゴで F に解決させる。
  - レイヤー（0始まりの小節番号）: 0〜1 = pad・pluck・bell（イントロ。キックなし）／2〜4 = kick・hat・bass・pad・pluck・arp／5 = kick・snare・bass・pad・lead・arp・bell（ヒーロー）／6 = pad・pluck（息をつく）／7 = stab・chime（ロゴ）
  - キュー: 小節4の4拍目に riser（終端が 9.375 秒）、小節5頭に impact、小節7頭に stab と chime。
  - 低域: サブベースなし、パッドは 160Hz ハイパス、キックの減衰は短く、ベースに倍音（R001、playbook §7.4）。
- 無音: 9.141〜9.375 秒（半拍）を音楽ゼロにし、逆再生 whoosh だけ（終端 9.375）。無音明けの impact が最重要の音。bgm.py で区間の無音を指定できなければ、master の前に該当区間をゼロにする。
- J カット: ロゴの riser 系スウェルを 12.656 秒（小節7の4拍目）から入れ、13.125 秒の stab に着地。L カット: ヒーローのきらめきの余韻を CTA の小節（11.25 秒〜）へ残す。
- サウンドロゴ: bell で D5–F5–A5–C6 の4音を小節1で鳴らし、ヒーローで星が結ばれるたびに1音ずつ応答、ロゴの chime で F に解決。
- 代案（比較用に別版を作る場合）: ライブラリ曲「M10_The Final Strike」（F minor。表示 129.2 BPM は量子化値なので downbeats で実測し直す）の推奨15秒区間 74.79〜89.79 秒。終わりがセクション境界 89.84 秒の直前にあたる。8 小節（約 14.9 秒）に映像を合わせる。公開範囲はユーザーに確認してから。

- DIRECTOR の見込み: フック 0 秒 ✓／ヒーロー 62.5% ✓／エンド 1.2 秒 ✓／カメラ3種 ✓／無音1回 ✓／J・L 各1回 ✓／結末の韻 ✓。

### 7. signature
- イージング: 線の描画と移動は (0.65,0,0.35,1)。ロゴ・CTA は臨界減衰ばね ω=18。テロップのチャンクはスケール 1.3→1 を 0.13 秒（back、オーバーシュート強め）。
- ずらし: チャンク 0.12 秒、星座の線は 16分音符（0.117 秒）ごと。
- 線: 太さ 3px（1080 幅）で一定、先端に灯金の光点（芯 3px＋グロー 15px）。描き終えた線は 35% に減光。
- 転換: すべて星と線が運ぶ。クロスフェードなし。
- モーションブラー: ホイップ（1.70–1.95）とプルバック（9.375–10.6）だけ N=8、ほかは N=1。テロップはブラーさせない。
- 仕上げ: ffmpeg でグレイン c0s=2、軽いビネット、夜藍のグラデにディザ。

### 8. build（固有の手順）
- `timeline.json` に 8 小節の時刻・テロップ（チャンク記法）・SE イベント・カメラキーを書き、bgm.py の song.json のキューも同じ小節番号から作る。
- 星座の線は、図形の頂点を事前に決めた4点（シード固定）へ移す。乱数は使わない。

### 9. gotchas
- Shippori Mincho B1 と Zen Kaku Gothic New を `__ready` で `document.fonts.load` する。しないと Canvas で明朝が別書体に化ける（R001）。
- 「まるごと」を 230px 前後で組むと 1080 幅で溢れる。`scrollWidth` で自動縮小（R001）。
- 3px の線は斜めでちらつきやすい。等倍クロップで確認し、必要なら 4px にする。
- 実績件数・顧客数などの数字を足さない（facts.json に無い）。
- 9.141〜9.375 の無音で、絵も一瞬止める（息を止める）。止めすぎて「静止 0.5 秒超」にならないよう、0.234 秒に収める。

### 10. start
- リード表と、0.0 / 1.9 / 3.8 / 6.1 / 8.9 / 9.4 / 10.6 / 11.5 / 13.2 / 14.5 秒のスチル 10 枚を出して自己批評し、最悪の3点を直す。一番難しい 2〜4 秒は 8.9〜11.3 秒（無音→ヒーロー）。
