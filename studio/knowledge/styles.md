作品のスタイルを選ぶための一覧。brief の §3 で、ここから1つ（多くて2つの掛け合わせ）を選ぶ。
選んだら §4 の書式でスタイルカードを brief に貼り、審査（`rubric.md` の style_fidelity）はそのカードに照らして行う。

## 3. あいまいな要望 → 具体的な変更

ユーザーやクライアントの言葉を、スタイルの中で変えてよい値に置き換える（lemo の MY-STYLES の考え方を当社用に整理）。

| 要望 | 具体策 |
|---|---|
| 高級感を出したい | 色数を減らす、明暗差を強める、動きを遅くする、余白を増やす、書体を細くする |
| 若々しく | 明るいアクセント、ビートでカット、弾むイージング、打楽器を増やす |
| 落ち着いた感じに | テンポを落とす、ホールドを長く、動く要素を減らす、楽器をまばらに |
| ブランドらしく | ブランド色は地ではなくアクセントに、タイトルにブランドの書体、ロゴは冒頭と末尾 |
| 和の雰囲気 | 明朝か筆文字、藍・朱・生成り、余白、箏や和太鼓、にじみや版の転換 |
| 分かりやすく | 1画面1メッセージ、字数を減らす、ホールドを長く、図解を足して文字を減らす |

1回の調整で変えるのは5項目まで。変更後は、元のスタイルと並べたスタイルフレーム（本番の描画コードで描いた静止画）で比べてから動画にする。

## 4. スタイルカード書式

スタイルの**不変条件（STYLE）**と、作品ごとの**作例（DEMO）**を分けて書く。同じスタイルで別の作品を量産しても既視感が出ないようにするため。

### 4.1 STYLE（全作品に共通する不変条件だけ。物語・尺・BPM・キーは書かない）
1. **本質と、そうでないもの**: 1〜2 文。混同しやすい隣のスタイルとの境界も書く。
2. **素材と描き方**: コードで何をどう模倣するか（線・面・質感・光）。
3. **色のロジック**: パレットではなくルール（地・図・アクセントの関係、発光してよい色、占有率）。
4. **文字とテロップ**: 書体、ウェイト、字間、テロップの入り方。
5. **動きの質**: イージング、ずらし、2コマ打ちか毎フレームか、重さ。
6. **カメラの文法**: 「動き / 表すもの / 使う場面」の3列の表。
7. **音のパレット**: 音楽のジャンル、SE の素材、ライブラリ曲か合成か。
8. **ネイティブムーブ**: このスタイルでしかできない瞬間。「こういう内容に合う」例を3つ。
9. **落とし穴**: 症状 → 対処。
10. **エンジン**: 再利用するコードの場所（`motion.js` の関数など）。
11. **変化の幅**: 構成・冒頭・結末を3案ずつ（いずれも過去の作例から遠いもの）。

### 4.2 DEMO（作例。1本ごとに書く）
- 冒頭に必ず「作例の1つにすぎない。物語・構成・ショット・小道具・タイミングを再利用しない」と書く。
- ショット表、音楽の構造、実際のパレット（HEX と占有率）、ビルド手順、審査の点数。

### 4.3 変えてよい範囲（3群）
| 群 | 中身 | 扱い |
|---|---|---|
| 安全に変えられる | 色（ロジックの範囲内）、書体、動きのテンポ、音のパレット、ネイティブムーブ1つ | 作品ごとに自由に変える |
| 性格が変わる | 素材と描き方、色のロジック自体、カメラの文法 | 変えるならスタイルフレームで比べ、brief に理由を書く |
| 変えてはいけない | 本質（4.1 の1）とエンジン | 変えたら別のスタイルとして新しいカードを作る |

### 4.4 1段落カード（短縮版。brief に貼る用）
次の要素を1段落に詰める（OPUSCAR 98 の書き方を参考にした当社の書式）:
- 色の HEX と画面の占有率（例: 「夜藍 #0E1430 が画面の約 70%」）
- 寸法は画面幅の比で（例: 「線の太さは画面幅の 1/360」）
- 仕上げ（グレインの強さ、ビネット、ブルームの対象）
- カットの間隔（例: 「1小節1カット、転換は2拍」）
- 看板ショット（1つ）
- 避けること（Avoid: 3〜5 個）

### 4.5 記入例: 天狼ナイト（STYLE の要約）
- 本質: 天狼星を唯一の光源とし、1本の光の線が場面を描いて運ぶ夜のモーション。星空の壁紙やキラキラのパーティクルとは違う（光るのは1点だけ）。
- 色: 夜藍 #0E1430 が地で約 70%、藍 #1B2350 の面が約 15%、文字は星白 #F4EEDF、補助線は灰青 #6B7699。灯金 #F2B544 は 10% 以下で、発光してよいのはこれと星だけ。純黒は使わない。
- 文字: 見出しは Shippori Mincho B1 800、小見出しは Zen Kaku Gothic New 500（字間 0.12em、灰青）。句点なし。
- 動き: 線は (0.65,0,0.35,1) で描き、角で減速。ロゴと CTA は臨界減衰ばね。描き終えた線は 35% に減光。
- カメラ: スロープッシュ（生きている）／ホイップ（星が場面を運ぶ）／プルバック（全体を明かす）。
- 音: 撥弦（箏風）・鐘・短いキック。ライブラリの和太鼓曲・エピック曲とも合わせられる。
- ネイティブムーブ: 描いた図形が星に縮み、線で結ばれて星座になる（サービスの統合、実績のまとめ、季節の星座ネタに合う）。
- 落とし穴: 細線のちらつき → 3〜4px と等倍確認／全部を光らせる → 灯金以外のブルーム禁止／暗すぎる → 文字のコントラスト 4.5:1 を測る。
