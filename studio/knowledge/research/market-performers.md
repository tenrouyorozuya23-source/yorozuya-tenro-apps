目的: 天狼スタジオが「高単価・すぐ品質が分かる」仕事を取るために、何を・どの尺で・どこに・いくらで作るかを決める。

## 0. 結論（先に読む）

1. **舞台・ライブの宣伝は「連作」で買われる**。ティザー → ソロ解禁 → 本予告 → カウントダウン → 追加公演・配信告知、という段階ごとに素材が要る。1本ではなく「公演宣伝パック」として売ると単価が上がり、テンプレートも使い回せる【5】【16】。
2. **個人向けの単発は安い市場**（配信画面 8,000〜12,000円、MV 5,000円〜など）。ここで値下げ競争をしない。当社が出るのは「3D・舞台照明の質で、制作会社の価格帯（数十万円〜）を取る」位置【3】【4】【12】【13】。
3. **企業の映像は中央値 46万円・平均 76万円。出演者・ロケ・CG 合成が加わると 100万円を超えやすく、3DCG アニメは 1分 100〜280万円**という帯がある。シネマティックな 3D ブランドフィルムは、この上の帯を狙える【1】【7】【14】【15】。
4. **SNS は「冒頭で理由を見せる」「音なしで成立」「縦 9:16」「15〜60 秒」が共通の型**。ロゴアニメや挨拶から入らない【9】【10】【11】【17】。当社の「暗転からの一灯」はフックとして強いが、**0.5 秒以内に光が入る**ことを守る。
5. 差別化の核は**照明と間**（direction.md）。市場の安価な制作物はフラットなモーショングラフィックスかイラストが中心【3】【12】なので、「Apple の製品映像のような 3D × 舞台照明」は見ただけで価格差の理由が伝わる。

## 3. 成果を出す要素（フック・字幕・投稿の型）

### 3.1 フック（冒頭）
- 冒頭 3 秒で結論か「見る理由」を見せ、**1本1メッセージ**、同じ型を量産して検証する【10】【11】。
- 構成の一例: フック 3 秒 → 本編 → CTA 5 秒（30 秒なら 3 / 22 / 5）【11】。
- 冒頭で避けるもの: 自己紹介、前置き（「お知らせがあります」）、**ロゴアニメーション**、挨拶【11】。→ 当社の作品は**ロゴを最後に回す**。
- 再生開始の遅れが 2 秒を超えると離脱が始まり、1 秒ごとに約 5.8% 増える（2012 年の研究。ショート動画ではない）【23】。→ 0 秒目から絵がある、ファイルを軽くする。
- 改善は「本編は同じで冒頭だけ 2 案」の A/B。3 秒到達率 → 視聴維持率 → 保存 → プロフィール遷移の順に見る【11】。

**当社の型（舞台の文法に置き換える）**
- 「暗転 → 一灯」は強いフックだが、**真っ暗は 0.5 秒まで**。0 秒目に何かが光っている状態で始める（playbook の P015 の教訓とも一致）。
- 情報の「謎」は1つだけ残し、**解禁日（次の楽しみ）**を必ず置く【5】。

### 3.2 字幕・文字
- X などは音声オフで自動再生されるため、冒頭の工夫と字幕が重要【17】。
- 動画広告に字幕を加えるとリーチと成果が上がることが多い（Google が紹介した 2023 年の米国調査）【24】。日本の「音声オフ率」の公的な数字は見つからなかった。
- 当社の既定: 日時・会場・タイトルは画面に**大きく**、可読時間は字数÷6 秒（playbook 5.2）。

### 3.3 投稿の時期と頻度
- ティザーの公開時期: **3か月前は認知、1か月前は具体的な情報、1〜2 週間前に謎の一部を明かす**。カウントダウンは 1〜2 週間前から【5】。
- 投稿の頻度は「多すぎるとすべての投稿には反応されない」との指摘があり、最適な回数の確かな数字は見つからなかった【25】。→ **公演宣伝の推奨（推定）**: 3か月前〜1か月前は週 1〜2 本、2 週間前から毎日 1 本（カウントダウン）、初日以降は感想・追加公演・配信告知を週 2〜3 本。
- リールのリーチはフィード投稿の平均 4.2 倍（運用代行 1 社・14 社のデータ。一般化に注意）【26】。
- 残席数を公開してチケット購入を呼びかけ、完売した例（ライブ）がある。残席の可視化は舞台にも使える【27】。
- 当社自身の X 投稿は 1 日 3 件まで（ガードレール）。

### 3.4 舞台・ライブ固有の型
- ソロビジュアルを 1 人ずつ → 全員のメインビジュアル → ロングスポット（長めの映像）【16】。
- 解禁を生配信と組み合わせ、アーカイブを無料公開【16】。
- 公演告知の絵コンテには、公演日程・チケット発売日・問い合わせ先を入れる構成が公的劇場の資料にもある【21】。
- 公演の記録映像・配信はコロナ以降の収益源として重視されている【28】【29】。→ 配信告知・アーカイブ予約の素材にも需要がある。

## 5. 企業が「シネマティック」なブランドフィルムに期待すること

| ロゴ・タグラインの印象づけ | 効果的な配置【6】 | ロゴは冒頭に出さず、最後に光の中で立たせる（§3.1） |
| 無形の価値を分かりやすく | 専門用語・無形商材を映像で【6】 | 精度・時間・手間を「光の線」「1 灯ずつ増える照明」に置き換える |
| SNS での拡散 | 自社 SNS での共有、若年層への訴求【6】 | 本編 60〜90 秒から 15・30 秒の縦版を必ず派生 |
| 質感の高さ | 有名カメラマンの起用で質感を上げた事例【38】 | 3D の PBR・被写界深度・正確な黒。Apple の製品映像の水準を物差しにする |
| 比較しやすい見本 | 発注側はイメージに近いサンプルを用意して共有する【38】 | **業種別のポートフォリオ作品を先に持っておく**（カタログの S06・S07） |
| 制作会社の得意分野 | ポートフォリオで得意分野を見極めて選ぶ【38】 | 「舞台照明 × 3D」の得意分野を作品で一目で分かるようにする |

費用を押し上げる要素: 撮影日数（1 日延長で 10〜30万円増）、プロの出演者（数十万円）、CG と複雑な視覚効果【7】。当社は**撮影なしの 3D**で同じ水準の画を出せるのが価格上の強み。実写が必要な案件は、バーチャルプロダクション（方式 A〜C）で後日対応する。

## 6. 当社への示唆（カタログ設計に反映したこと）

1. **シリーズ化**: 同じ 3D 舞台・照明プリセット・文字組みを使い回せるよう、10 シリーズ × 10 本にした。
2. **連作で見せる**: 公演 1 本分（ティザー → ソロ解禁 → 本予告 → カウントダウン → LP）を架空公演でまとめて作り、「パック」の見本にする。
3. **縦横の両方**: 本編 16:9 から 9:16・1:1・6 秒版を派生する（playbook の R&D 候補とも一致）。
4. **音なしで成立**: すべての SNS 作品で、日時・場所・タイトルを画面だけで読めるようにする。
5. **ロゴは最後**: 冒頭 0.5 秒以内に光と主役。
6. **価格の見本**: 企業向けは業種別（精密・酒造・建築・ホテル・IT）、製品向けは素材別（金属・ガラス・樹脂・鏡面）に作品を揃え、発注側の「サンプル」に使ってもらう。
7. **架空のクライアントだけ**: 実在の団体名・商標に似た名前を避け、公開前に名前の重複を検索で確認する（なりすまし禁止のガードレール）。

### 調べきれなかったこと（次の調査候補）
- 舞台ティザー・公演特設サイト・アイドルの煽り映像・VJ の**日本での単価**（公開データなし。実際の見積もり依頼の募集や、業界の人への聞き取りが必要）。
- 日本の SNS での**音声オフ率**、プラットフォーム別の**最適な投稿頻度**（公式・統計的な数字なし）。
- 劇団の稽古動画・メイキングの集客効果。
