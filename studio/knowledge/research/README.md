## 再利用のきまり（まとめ）
- MIT のコードを流用するときは、そのファイルに著作権表示を残し、リポジトリの CREDITS に記録する。動画の画面にクレジットは不要。
- CC BY の文章を改変して使ったファイルには、末尾に出典と改変の旨を書く（brief-template.md で実施済み）。
- ライセンスのないもの・第三者のプロンプト・他人の映像・曲・キャラは、学ぶだけで使わない。
