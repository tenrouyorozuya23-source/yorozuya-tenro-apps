## 前提

- **クライアントはすべて架空**。実在の団体・商標に似た名前を避けたが、公開前に必ず名前を検索して重複がないか確かめる（なりすまし禁止）。
- 方向性は `direction.md`（洗練・3D・舞台照明、イラスト調にしない）。スタイル番号は `styles.md` の一覧。既定は 0' 天狼シネマ。
- 音楽の ID は `music-library/catalog.md`（TNR-M00〜M14）。「合成」は `tools/bgm.py`、「支給」はユーザーの SUNO 新曲など。
- needs: **cloud-ok** = 今のクラウド環境（three.js / Canvas / HTML / 合成音）で作れる、**needs-mac** = Mac mini と Blender（4K・長尺・流体・Cycles）が要る、**needs-footage** = 実写・写真・収録などの素材が要る。
- priority: **1** = 先に作る（高単価の受注に直結し、今作れる）、**2** = 次に作る、**3** = 余裕があれば。
- 作品間で図像を使い回さない（焼き直し禁止）。テンプレートで共有するのは空間・照明・文字組みの部品だけ。
