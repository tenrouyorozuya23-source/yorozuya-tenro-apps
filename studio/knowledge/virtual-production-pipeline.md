# 天狼スタジオ バーチャルプロダクション・パイプライン

**監督は天狼さん、エンジニアリングは Claude。** 少人数（1〜3人）で、3DCG とグリーンバック撮影・合成・カメラ連動・モーションキャプチャまでを仕事にするための仕組み。
作成: 2026-11-05。機材価格は Apple 公式ストアで同日確認した値（税込）。

---

## 1. 役割分担

| 担当 | やること | やらないこと |
|---|---|---|
| **天狼さん（監督・ディレクター）** | 企画の方向を決める、3案から選ぶ、演技と画を見て「OK／ここを直して」を言う、現場で役者に指示する、照明の雰囲気を決める | 細かい設定・数値調整・ソフトの操作 |
| **Claude（テクニカルディレクター／CG／合成／編集補助／音）** | 企画書と絵コンテ、CG空間（Blender）の制作、照明設計図、撮影香盤と機材セッティング表、合成（キー抜き・カメラ解析・CG背景のレンダー）、モーションの適用、色と音の仕上げ、各形式での書き出し、品質審査 | 現場での物理的な作業（カメラ・照明・グリーンバックの設置） |
| **現場スタッフ（必要なら1〜2人）** | カメラ操作、照明の設置、役者のケア | 合成や CG の設定（Claude が表で指示する） |

監督が触るのは3つだけ: **管理アプリ**（承認とコメント）、**撮影当日のチェックリスト**（スマホで見る）、**素材を入れるフォルダ**。

## 2. 撮影方式（3段階。易しい順に導入）

| 方式 | 内容 | 向いている仕事 | 現場で見えるもの | 仕上げ |
|---|---|---|---|---|
| **A. 固定カメラ＋事前レンダー背景** | カメラは三脚で固定。Blender で作った背景（静止画か、ゆっくり動く映像）を、OBS でリアルタイムにキー合成 | ライバー・アイドルの配信、インタビュー、トーク番組風 | 完成に近い合成（そのまま配信・収録できる） | 撮って出し、または後日きれいに再合成 |
| **B. iPhone トラッキングで動くカメラ** | カメラに iPhone を載せ、Lightcraft Jetset でカメラの動きを記録しながら現場で簡易合成を見る | MV、CM、ドラマ風、商品紹介 | 簡易合成のプレビュー（構図と演技の確認用） | 後日、記録したカメラの動きで Blender の CG を本番品質で描いて合成 |
| **C. 素材だけ撮って後日すべて合成** | 現場はグリーンバックで撮るだけ。カメラの動きは映像から Blender で解析 | 予算・時間が限られた案件、追加カット | 素の映像 | 後日すべて Claude が合成 |

**正直な前提**: Mac と Blender では、「動くカメラ＋本番品質の CG」をその場でリアルタイムに描くことはできない（それは UE5＋NVIDIA の領域）。そのため、現場はプレビュー品質（方式 B）か、固定カメラの完成合成（方式 A）、本番品質は後日（Blender）という分担にする。

## 3. 機材

### 3.1 Mac mini（Apple 公式ストア 2026-11-05 時点・税込）

現行は M6 チップ（12コアCPU／12コアGPU、メモリ最大32GB）と M5 Pro チップ（15コアCPU／16コアGPU、上位は18コアCPU／20コアGPU、メモリ最大64GB）。
3DCG・合成・リアルタイム処理には **M5 Pro（18コアCPU／20コアGPU）** を選ぶ。M6 は GPU とメモリ上限が足りない。

| 項目 | 価格 |
|---|---|
| M5 Pro 基本構成（15コアCPU／16コアGPU・24GB・512GB） | 299,800円 |
| チップ: 18コアCPU／20コアGPU | +36,000円 |
| メモリ: 48GB / 64GB | +108,000円 / +180,000円 |
| SSD: 1TB / 2TB / 4TB / 8TB | +54,000円 / +144,000円 / +324,000円 / +684,000円 |
| 10Gb Ethernet | +18,000円 |
| Final Cut Pro / Logic Pro（任意） | +50,000円 / +30,000円 |

| 構成案 | 内容 | 合計 |
|---|---|---|
| **推奨** | M5 Pro 18C/20G・**64GB**・1TB・10GbE | **587,800円** |
| 余裕あり | M5 Pro 18C/20G・64GB・2TB・10GbE | 677,800円 |
| 予算を抑える | M5 Pro 18C/20G・48GB・1TB・10GbE | 515,800円 |

**採用予定（ユーザーの予算: ペイディの Apple 枠 29万円以内、2026-11-05）**

| 構成 | 価格 |
|---|---|
| **M6（12コアCPU／12コアGPU）・32GB・512GB** ← 採用予定 | **257,800円** |
| 同上＋10Gb Ethernet | 275,800円 |
| M6・24GB・1TB | 275,800円 |
| M6・32GB・1TB | 311,800円（枠超え） |

- ストレージ方針: 内蔵 2TB（M6・32GB・2TB は 401,800円）は枠を超えるため、本体は 512GB にし、外付け SSD を別途購入する。内蔵は OS・アプリ・一時ファイル、外付けは素材・プロジェクト・書き出し。
  - **M6 の背面端子は Thunderbolt 4（40Gb/s）×3、前面 USB-C は 10Gb/s×2**（Thunderbolt 5 は M5 Pro のみ）。→ **USB4（40Gbps）対応の完成品 SSD・4TB** を背面に接続（例: SanDisk Extreme PRO USB4、4TB で 99,800円の表示あり 2026-11）。Thunderbolt 5 SSD は M6 では TB4 速度になるので不要。USB 3.2 Gen 2x2（20Gbps）は Mac 非対応で 10Gbps に落ちるため避ける。
  - 2026年は SSD 価格が高騰中（2027年後半まで高止まりの見方）。購入前に最新価格を確認。
  - **決定（2026-11-05）**: 外付けはユーザー所有の 4TB SSD を使う（接続規格は要確認）。Google Drive の空き約 2TB を保管・共有・バックアップに使う。
- 保存の運用ルール:
  - 内蔵 512GB: OS・アプリ・作業用ファイル。常に 100GB 以上空ける。
  - 外付け 4TB: 撮影素材・CG プロジェクト・作業中の案件・書き出し（作業はここで行う）。
  - Google Drive 2TB: 完成品・報告書・共有・終わった案件のバックアップ。パソコン版は「ストリーミング」設定（ミラーリングにしない）、キャッシュは外付けに置く。Drive 上の素材を直接編集しない。
  - 撮影素材は撮影当日に Drive か HDD へ2部目をコピー（Claude が自動化）。
  - 熱対策: 外付け SSD は Mac mini と重ねず横に離して置く（Mac mini の吸排気をふさがない）。熱くなるのは大量コピーと CG 連番の長時間書き出し。Claude は SSD の温度を読める機種なら重い作業の前後で確認し、高温なら書き出しを一時停止して冷めてから再開。CG 連番は内蔵に一時書き出しし、完成した動画だけ外付けへ移す。必要なら小型 USB ファンを追加。
  - Claude は毎サイクル、内蔵・外付け・Drive の空き容量を確認して管理アプリに表示し、内蔵の空きが 100GB を切ったら警告、納品済み案件は Drive へ移して SSD を空ける。
- 認定整備済製品（2026-11-05 確認）: 枠内は M4（10コアCPU/10コアGPU）・24GB・512GB の 175,800円のみ（M4 Pro は 497,800円〜で枠超え）。ペイディあと払いプランApple専用は整備済製品にも使える。メモリ32GBと GPU・世代の差を重視し、新品 M6・32GB を推奨と判断。
- M5 Pro は基本構成でも 299,800円で枠を超えるため、M6 の上限メモリ 32GB を優先し、SSD は外付け（2〜4TB）で補う。
- M6 での運用方針: プレビュー設定（低解像度・低サンプル）と本番設定（夜間にまとめて書き出し）を分ける。Cycles の本番は時間がかかる前提。大きな CG シーンと 4K 多重合成の同時作業は避ける。
- 書き出しが追いつかなくなったら、書き出し専用機（GPU 付き PC か上位の Mac）またはクラウド GPU を追加する。

- メモリは後から増やせない。CG シーン・4K 素材・リアルタイム合成を同時に扱うので、予算が許せば 64GB（M5 Pro）が理想。
- 内蔵 SSD は 1TB に抑え、素材と書き出しは外付けの Thunderbolt SSD（4TB 以上）に置くのが安い。
- Final Cut Pro は必須ではない（DaVinci Resolve の無料版でも足りる）。

## 4. 案件の流れ（監督がやること／Claude がやること）

| 段階 | 監督（天狼さん） | Claude |
|---|---|---|
| 1. ヒアリング | クライアントの要望を管理アプリに書く（箇条書きでよい） | 要望を整理し、足りない情報を質問リストにする |
| 2. 企画 | 3案から1つ選ぶ／言葉で直しを入れる | 企画書、3案、絵コンテ（静止画）、CG 空間のプレビュー |
| 3. プリプロ | 照明の雰囲気・役者の動きのイメージを伝える | Blender で CG 空間を作る、照明設計図（ライトの位置・角度・色）、撮影香盤、機材セッティング表、当日チェックリスト |
| 4. 撮影 | 演出に集中。チェックリストを上から順に見るだけ | （事前に）OBS のシーン設定・Jetset に読み込む CG・命名ルールを用意 |
| 5. 取り込み | 素材フォルダに入れる（カードの中身をそのままコピー） | 自動でキー抜き、カメラの動きの解析、CG レンダー、合成の初稿 |
| 6. チェック | 管理アプリで動画を見て「何秒のここを直して」と書く | 1回にまとめて修正、別エージェントで品質審査 |
| 7. 納品 | OK を出す | SNS縦・横・サイネージなど各形式で書き出し、納品フォルダに整理 |

## 7. 品質の物差し

- `direction.md` の方向性（Apple の製品映像のように洗練・三次元的、舞台照明で語る）を、合成でも守る。
- 合成のよくある失敗をチェックする: 緑のかぶり、髪の毛のエッジ、人物と背景の光の向きの不一致、影がない、カメラの揺れと CG のズレ、色温度の違い。
- 実写の照明と CG 側の照明の向き・色・硬さを、照明設計図で必ず揃える（ここが舞台照明の経験が最も活きる所）。
