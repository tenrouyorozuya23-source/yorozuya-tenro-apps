## 使い方のルール

- 使う曲は `catalog.json` の `tags`・`use` から選び、映像の拍は `analysis/<drive_id>.json` の `beats` / `downbeats` を `render.mjs --data` に渡して合わせる。
- 切り出しは小節頭で始めて小節頭かセクション境界で終える。終わりは 0.3〜0.6 秒のフェードか、セクション境界の自然な終止を使う。
- 書き出し時は必ず -14 LUFS / TP -1 dB に正規化（`master.py`）。TNR-M13 は元が -26 LUFS と小さい。TNR-M05・M07 は低域が厚いのでスマホ向けは 100Hz 以下を 2〜3dB 下げる。
- BPM が 140 超の曲（M09・M11）はハーフタイムで感じる可能性がある。映像のカットは2拍単位を基本にする。
- 新しい音源が Drive に追加されたら、ダウンロード（10MB超は drive.usercontent の直接リンク）→ 解析 → このカタログに追記する。
- 和風・ダーク系が中心なので、明るいコーポレート系や Lo-fi は合成 BGM（`bgm.py`）で補う。
